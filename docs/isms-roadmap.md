# ISMS / fail-safe 改善ロードマップ

このプロジェクトでは、ISO/IEC 27001の正式な認証・準拠そのものではなく、ISMSを意識した安全運用に近づけることを目的に、段階的な改善を進めます。

## 今後の改善課題

- 監査ログを作る
- 重要操作の確認を強くする
- 管理者・センター長権限を見える化する
- バックアップ・復旧手順を書く
- 個人情報の表示範囲をさらに絞る
- エラー時の案内を統一する

## 今回の着手状況

監査ログの土台を追加しました。利用者・管理者による主要操作について、実行者、権限、対象、内容、日時を記録し、管理者が後から確認できるようにしています。監査ログの記録に失敗しても本体操作は継続する設計です。
