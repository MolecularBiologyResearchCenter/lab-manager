# ISMS / fail-safe 改善ロードマップ

このプロジェクトでは、ISO/IEC 27001の正式な認証・準拠そのものではなく、ISMSを意識した安全運用に近づけることを目的に、段階的な改善を進めます。

## 今後の改善課題

- 監査ログを作る
- 重要操作の確認を強くする（利用者削除時の氏名入力確認、権限変更時の変更前後表示を追加）
- 管理者・センター長権限を見える化する（利用者管理画面に権限別人数カードを追加）
- バックアップ・復旧手順を書く
- 個人情報の表示範囲をさらに絞る
- エラー時の案内を統一する

## 今回の着手状況

監査ログの土台を追加しました。利用者・管理者による主要操作について、実行者、権限、対象、内容、日時を記録し、管理者が後から確認できるようにしています。監査ログの記録に失敗しても本体操作は継続する設計です。今回、利用者管理画面で権限別人数を表示し、権限変更の変更前後表示と監査ログ記録の案内、利用者削除時の氏名入力確認を追加しました。
